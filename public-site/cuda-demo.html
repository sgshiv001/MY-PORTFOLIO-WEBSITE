What changed and why

One split, two classifiers

Four launches instead of six

Each fused convolution block stages its input in shared memory. Four lanes compute a pooling window and exchange their maxima, so the full convolution tensor never goes to global memory.

Fair timing scopes

CPU is single-thread PyTorch. Copy-inclusive GPU timings include upload, inference, and download. Resident timings keep the input on the device. All exclude setup.

Scope of the evidence

This is a small, fixed-shape digit benchmark. Results reflect this split and laptop. The browser replays the captured results; the Windows implementation runs the native kernels.
